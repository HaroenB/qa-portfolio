# QA & Software Portfolio

A responsive single-page portfolio showcasing practical software testing, test automation, development and workflow automation projects.

## Portfolio Focus

The site highlights work across:

- Manual QA and exploratory testing
- Selenium test automation with C#
- NUnit and Reqnroll/BDD
- Accessibility investigation and Axe testing
- Python and pytest
- SQL and relational database validation
- Jira defect evidence
- n8n workflow automation
- Git and GitHub

## Featured Projects

### Finding Hospitals QA Automation

Started from an existing Selenium/NUnit training framework and extended and adapted it with manual testing, additional BDD regression coverage, accessibility investigation, Jira evidence and release documentation.

### Python Snake Game

An academic Pygame project that was reviewed and improved with movement edge-case handling, safer food spawning, refactored testable logic and automated pytest coverage.

### Computer Shop Database

An academic Microsoft Access database reviewed for SQL correctness, relationship structure and data quality. A privacy-safe SQL portfolio version was produced after validating and correcting joins.

### QA Test Results Summary

A personal n8n workflow that processes synthetic test results, calculates QA metrics and routes execution through validated success and failure paths.

## Technologies

HTML, CSS and JavaScript are used directly without a front-end framework.

## Running Locally

Open `index.html` in a modern web browser.

No package installation, build process or external service is required.

## Evidence and Privacy

Only selected portfolio-safe evidence is included. Local file paths, credentials, private account details and unnecessary personal information are excluded.

## Responsible AI Use

AI assistance was used during planning, wording and development support. The implementation, project evidence, testing decisions and final content were manually reviewed and validated.
